Definición de Modelo Operativo
Definición operativa de “abandono escolar”
En este sistema, se define abandono escolar como:
Estudiante que interrumpe su trayectoria educativa durante el curso académico sin actividad académica verificable durante un periodo prolongado.
Variables necesarias
Para poder construir la etiqueta “y” el dataset debe incluir:
Académicas:
	asistencia_pct: entero, porcentaje de asistencia
	nota_media:  entero, promedio de calificaciones
	materias_suspensas: entero, numero de asignaturas no aprobadas
	numero_materias_curso: entero, número de asignaturas totales del curso
	evaluaciones_realizadas: entero, número de evaluaciones realizadas
Administrativa:
	matricula_activa: booleano, 1 sí, 0 no
	oferta_educativa: entero, 1 -> ESO; 2 -> Bachillerato; 3 -> FP Básica; 4 -> FP Grado Medio.
Comportamiento temporal:
	días_sin_actividad: entero, días sin registro educativo
	inasistencias_consecutivas: entero, faltas seguidas
Demograficas:
	grado_urbanización: entero, 1 -> Rural; 2 -> Semiurbano; 3 -> Urbano
Socio-educativas:
	distancia_escuela: entero, distancia en KM con la escuela
	acceso_internet: booleano (1 sí, 0 no)
	nivel_socioeconomico: entero, asociado a la clase social, 1-> Alta; 2->Media Alta; 3-> Media; 4->Media Baja; 5-> Baja Alta; 6-> Baja Baja
	apoyo_familiar: booleano (1 sí, 0 no)
	trabaja: booleano (1 sí, 0 no)






Reglas de etiquetado (ground truth)
Nuestra variable ‘y’ será abandono, booleano (1 sí, 0 no).
Regla principal (abandono confirmado)
Un estudiante etiquetado como:
Y  = 1 (abandono) si se cumple cualquiera
R1 – Abandono administrativo
matricula_activa == 0
R2 – Inactividad crítica
dias_sin_actividad >= 60
AND asistencia_pct < 20
R3 – Desvinculación académica severa
evaluaciones_realizadas == 0
AND asistencia_pct < 30 
AND (nota_media is null or nota_media < 3/10)

Regla de estabilidad
Y = 0 (estudiante estable) si:
matricula_activa == 1
AND asistencia_pct >= 75
And evaluaciones_realizadas > 0

Zona intermedia (no abandono confirmado)
Estos casos se etiquetan como 0 por defecto o pueden excluirse:
	asistencia entre 30% y 75%
	bajo rendimiento sin desconexión total

Casos límite (Edge cases)
Caso 1 – Baja asistencia pero matrícula activa
	asistencia 40%
	evaluaciones realizadas
	solución: NO es abandono (riesgo Sí, abandono No)
Caso 2 – Sin datos de notas
	nota_media = sin información
	usar solo asistencia + actividad
Caso 3 – Abandono tardío (mitad del curso)
	si dias_sin_actividad >=60 al final del periodo  abandono
Consideración entre abandono y riesgo

Gestión de valores faltantes
Definición de una política de missing values

	Nota_media, gestión del caso de null.
	Para variables numéricas, mediana por oferta educativa
	Para variables binarias, considerar una categoría aparte.
	Si faltasen:
	Asistencia
	Matrícula
	Actividad
Entonces el registro debe excluirse o marcarse como inválido.
Indice de riesgo socioeconómico
La idea es construir un índice continuo de riesgo entre 0 y 1, donde:
	0 = riesgo mínimo 
	1 = riesgo máximo 
El objetivo no es confirmar abandono (eso ya lo hacen las reglas de etiquetado), sino estimar la probabilidad o vulnerabilidad de que el estudiante termine abandonando.
Principio del índice de riesgo de abandono
El índice debe:
	Penalizar: 
	baja asistencia 
	bajo rendimiento 
	desconexión académica 
	vulnerabilidad socioeconómica 
	Incrementar riesgo cuando: 
	trabaja 
	no tiene internet 
	no tiene apoyo familiar 
	vive lejos
Normalización de variables.
Es necesario gestionar este problema
No todas las variables están:
	en la misma dirección semántica 
	en la misma escala 
	ni con la misma sensibilidad estadística 
Algunas variables representan:
	riesgo creciente 
	otras protección 
	otras categorías ordinales 
Necesitamos estandarizar:
	dirección del riesgo, para mantener dirección coherente.
	Rango, en escala [0,1]
	impacto relativo

Primero transformamos todas las variables a escala común [0,1].
Variables académicas

R_asistencia=1-(asistencia_pct)/100

R_asistencia=1-(asistencia_pct)/100
