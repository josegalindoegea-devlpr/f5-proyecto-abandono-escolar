Desarrolla un programa profesional en Python para generar datasets sintéticos destinados al entrenamiento de modelos de Inteligencia Artificial orientados a la detección de “abandono escolar”.

El programa debe estar completamente documentado, estructurado y optimizado para escalabilidad, mantenibilidad y calidad de datos.

Objetivo

Generar un dataset sintético coherente y realista en formato CSV que permita entrenar modelos de clasificación supervisada para detectar abandono escolar.

El dataset debe incluir:

variables académicas
administrativas
temporales
socioeducativas
demográficas
una variable objetivo (abandono_escolar)

La generación no debe ser completamente aleatoria, sino basada en reglas y correlaciones realistas entre variables.

Reglas del modelo de abandono

La variable abandono_escolar será igual a 1 si se cumple cualquiera de las siguientes reglas:

R1 – Abandono administrativo
matricula_activa == 0
R2 – Inactividad crítica
dias_sin_actividad >= 60
AND asistencia_pct < 20
R3 – Desvinculación académica severa
evaluaciones_realizadas == 0
AND asistencia_pct < 30
AND (
    nota_media is null
    OR nota_media < 3
)
Reglas de coherencia del dataset

El generador debe crear relaciones realistas entre variables.

Coherencias obligatorias
1. Baja asistencia

Si:

Entonces aumentar probabilidad de:

suspensos altos
baja nota

2. Sin evaluaciones

3. Matrícula inactiva

Si:

matricula_activa == 0

Entonces incrementar probabilidad de:

abandono
4. Repetidor

Si:

Repetidor_curso_actual == 1

suspensos

abandono
5. Vulnerabilidad social

Combinar:

trabaja == 1
sin apoyo familiar
sin internet
